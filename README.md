# Abel Isaac Abraham — Personal Website

A premium editorial-style personal website for Abel Isaac Abraham, built with React, Vite, Tailwind CSS, and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run typecheck
npm run build
npm run preview
```

The project is ready for Vercel or any static hosting provider. Vercel can use the default Vite settings: build command `npm run build` and output directory `dist`.

## Personal details to customize

The site includes Abel's supplied photos and Instagram link. Before publishing, update any remaining placeholder contact or social links in `src/App.tsx` and the canonical URL/social metadata in `index.html`.
